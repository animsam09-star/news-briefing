## 1. 공통 설정
═══════════════════════════════════════

**Telegram (환경변수 — 값 하드코딩 금지)**

메시지는 **임시 파일에 진짜 줄바꿈으로 작성한 뒤 파일 경유로 발송**한다. 메시지 1개당 파일 1개(`/tmp/msg1.txt`, `/tmp/msg2.txt` …).
```
# 1) 작성 — heredoc 안에서는 개행이 그대로 개행으로 들어간다
cat > /tmp/msg1.txt <<'EOF'
📰 ...
━━━ 건설/부동산 ━━━
기사 제목
https://tinyurl.com/xxxxxxx

기사 제목
https://tinyurl.com/xxxxxxx
EOF

# 2) 발송 직전 전문 출력 (필수 — Actions 로그에 실제 발송본을 남겨 형식 검증)
cat /tmp/msg1.txt

# 3) 발송 — text@파일 형식이면 curl이 파일 내용의 개행을 %0A로 정확히 인코딩
curl -s "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d "chat_id=${TELEGRAM_CHAT_ID}" --data-urlencode "text@/tmp/msg1.txt"
```

**줄바꿈 절대 규칙 (2026-07-27 사용자 지적)**: 셸 인자 안에 `\n`(백슬래시+n) 두 글자를 넣으면 curl이 그 두 글자를 그대로 인코딩해 **Telegram에 리터럴 `\n`이 텍스트로 표시된다**. 개행은 언제나 파일 안의 진짜 줄바꿈이어야 하고, 발송은 위의 `text@파일` 형식으로만 한다. `--data-urlencode "text=...\n..."` 직접 전달 금지.

plain text, 3000자 초과 시 분할, 한국어.

**시간 윈도우**: `pool.json`의 `windows_kst`가 확정값 (평일: 당일 09:50~14:05 / 월: 금 14:00~월 14:05). 재계산 금지.

**절대 금지**
1. pool.json 밖 기사 임의 추가 금지 (폴백은 `--adhoc-naver`로만).
2. 창밖 기사·날짜/URL 확인 불가 기사 포함 금지.
3. 거짓말/수치 조작 금지. 모르면 "미확보". 폴백 카운트 거짓 기록 금지.
4. 검증되지 않은 내용 추가 금지.
5. 정치 뉴스 필터: 여야 정치·선거·여론조사·정책 찬반 논쟁 제외. 정부 부처 정책 발표·입법 의결 자체는 포함.

## 2. 실행 파이프라인
═══════════════════════════════════════
1. `pool.json` 읽기 (`Read` 도구).
2. `method1.건설` / `method1.금융`에서 §3·§4 우선순위·제외 규칙으로 각 10건 선별. `allowed_media: false` 제외. 중복 제거(§7).
3. 미달 시 폴백: `python scripts/collect.py --slot afternoon --adhoc-naver "<확장키워드>" --category <건설|금융>` — 키워드당 1회 상한, 도메인 가드(원 카테고리 유지), 포괄 키워드 "건설"·"부동산" 단독 금지.
4. 제목 복원 (필수): 네이버 API는 긴 제목을 "..."로 절단한다. 선별 확정 기사 중 `title_truncated: true`인 건은 `python scripts/full_title.py <URL...>`로 전체 제목 복원 — **`naver_link`가 있으면 그것을, 없으면 `url`을 전달** (여러 URL 동시 전달 가능). 복원 제목 끝의 " - 매체명"·" | 매체명"·" :: 매체명" 꼬리는 제거. 복원 실패(null) 시 잘린 제목 그대로 발송 + 푸터 "제목복원 실패 N건". 잘린 제목("...")을 복원 시도 없이 발송하는 것 금지.
5. TinyURL 축약 (선별 확정분만) → 게이트 검증(§0) → 발송(§8).
