# evening 뉴스 브리핑 (21:30 KST) — v9-gha (GitHub Actions판)

매일 오후 9시 30분 뉴스 브리핑을 Telegram으로 발송한다. 방식1(건설/부동산 10건 + 경제/금융 10건, 제목+URL만, 요약 없음) 단일.

**v9-gha (2026-07-24)**: GitHub Actions 이관. 수집·시간윈도우 검증은 `scripts/collect.py`가 실행 전에 완료(→ `pool.json`). 이 프롬프트의 역할은 **선별 → 게이트 → 발송**. 키워드·우선순위·게이트·메시지 형식(v7)은 기존과 동일.

## 0. 누락 제로 하드 게이트 — 발송 전 절대 조건
═══════════════════════════════════════

**이 태스크(evening) = 방식1 단일.**

- **G0-1. URL 무결성**: 발송 메시지 `https?://` 개수 = 발송 기사 개수. 목표 20 URL. `google.com/url?` 잔류 0건.
- **G0-2. 방식 매니페스트**: 건설+금융 두 섹션 모두 발송 완료 전 "완료" 선언 금지. 0건 섹션도 명시 후 발송.
- **G0-3. 기사 수 정합성**: 미달 시 "※ N건만 확인됨 (폴백 △회 실행 후)" 명시. 숨김 금지.
- **G0-4. 푸터 로그 (필수)**: `URL <실제>/20, 방식1 건설 <N> + 금융 <M>, 수집기 naver <K>쿼리, 창밖 기계제외 <X>건, 폴백 <F>회, 단축 실패 <S>건`. 푸터 누락 시 완료 선언 금지.
- **G0-5. 날짜 검증 (collect.py 위임)**: 윈도우 필터는 collect.py가 pubDate 기준으로 수행 완료. pool.json 밖 기사 추가 금지 — 폴백도 `--adhoc-naver`로만 (동일 필터 자동 적용). LLM의 날짜 해석·완화 금지.

## 1. 공통 설정
═══════════════════════════════════════

**Telegram (환경변수 — 값 하드코딩 금지)**
```
curl -s "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d "chat_id=${TELEGRAM_CHAT_ID}" --data-urlencode "text=메시지내용"
```
plain text, 3000자 초과 시 분할, 한국어.

**시간 윈도우**: `pool.json`의 `windows_kst`가 확정값 (평일: 당일 14:05~21:20 / 월: 금 14:00~월 21:20). 재계산 금지.

**절대 금지**
1. pool.json 밖 기사 임의 추가 금지 (폴백은 `--adhoc-naver`로만).
2. 창밖 기사·날짜/URL 확인 불가 기사 포함 금지.
3. 거짓말/수치 조작 금지. 모르면 "미확보". 폴백 카운트 거짓 기록 금지.
4. 검증되지 않은 내용 추가 금지.
5. 정치 뉴스 필터: 여야 정치·선거·여론조사·정책 찬반 논쟁 제외. 정부 부처 정책 발표·입법 의결 자체는 포함.

## 2. 실행 파이프라인
═══════════════════════════════════════
1. `pool.json` 읽기 (`Read` 도구).
2. `method1.건설` / `method1.금융`에서 §3·§4 우선순위·제외 규칙으로 각 10건 선별. `allowed_media: false` 제외. 중복 제거(§7).
3. 미달 시 폴백: `python scripts/collect.py --slot evening --adhoc-naver "<확장키워드>" --category <건설|금융>` — 키워드당 1회 상한, 도메인 가드(원 카테고리 유지), 포괄 키워드 "건설"·"부동산" 단독 금지.
4. TinyURL 축약 (선별 확정분만) → 게이트 검증(§0) → 발송(§8).

═══════════════════════════════════════
**선별 우선순위:**
1. 금융 규제/감독 정책 변화 (금감원·금융위 조치, 대출/자본규제 변경)

3. 자본시장 제도

**제외**: 증권사 리포트/목표가("[리포트 브리핑]"·"목표가 상향"), 주가 단순 보도("52주 신고가"·"사이드카").

## 8. 메시지 형식 (v7: 제목 + 단축URL, 번호·화살표 없음)
═══════════════════════════════════════
- 모든 URL은 TinyURL 축약: `https://tinyurl.com/api-create.php?url=<원본URL>` GET → 응답 본문이 단축 URL. 실패 시 해당 건만 원본 fallback + 푸터 "단축 실패 N건".
- 번호(1.)·화살표(→) 사용 금지. 제목 한 줄, 다음 줄에 단축 URL. 기사 간 빈 줄 없음. 섹션 헤더는 유지.

```
📰 오후 10시 뉴스 브리핑 (YYYY.MM.DD)

━━━ 건설/부동산 ━━━
기사 제목
https://tinyurl.com/xxxxxxx
기사 제목
https://tinyurl.com/xxxxxxx
...

━━━ 경제/금융 ━━━
기사 제목
https://tinyurl.com/xxxxxxx
...

━━━ 발송 검증 ━━━
URL 20/20, 방식1 건설 10 + 금융 10, 수집기 naver K쿼리, 창밖 기계제외 X건, 폴백 F회, 단축 실패 0건
```
