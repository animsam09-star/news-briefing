매일 오전 6시 20분 뉴스 브리핑을 Telegram으로 발송한다. 방식1(건설/부동산 10건 + 경제/금융 10건, 제목+URL만) + 방식3(글로벌 13테마, 3단 포맷).

**공통 지침 (기존 유지)**:
1. **정치 뉴스 필터링**: 여당·야당 정치 뉴스(선거 여론조사, 보궐선거, 당대표·의원 발언, 당내 동향, 후보 동정, 정당 논평)·정책 평가/지지율 여론조사·정책 찬반 논쟁 기사는 모두 제외. 단, 정부 부처의 정책 발표·새 제도 시행·국회 입법 의결·법안 통과(공식 발표 자체)는 포함.
2. **URL TinyURL 축약**: 발송 URL은 전부 `curl -s "https://tinyurl.com/api-create.php?url=<URL_ENCODED_원본>"`으로 축약. 실패 시 해당 건만 원본 URL + 푸터에 "TinyURL 실패 N건".
3. **형식·줄 간격 (v7 통일 — 2026-07-27 사용자 지침)**: 다른 세 슬롯(midmorning·afternoon·evening)과 동일한 v7 형식을 쓴다. **번호(1. 2. 3.)와 화살표(→) 사용 금지.** 방식1은 `제목` 줄 + `단축 URL` 줄, 방식3은 `제목` 줄 + `- 요약` 줄 + `단축 URL` 줄. **기사 사이에는 빈 줄 1개.** 정확한 형태는 §8 템플릿이 유일한 기준이며, 개행은 §1의 파일 경유 발송으로 진짜 줄바꿈이어야 한다.

5. **파일 저장 금지**: Telegram 발송만 수행. 리포지토리에 산출물 파일을 남기지 않는다 (`/tmp` 임시 작업은 허용).

## 1. 공통 설정
═══════════════════════════════════════

**Telegram (환경변수 — 값 하드코딩 금지)**

메시지는 **임시 파일에 진짜 줄바꿈으로 작성한 뒤 파일 경유로 발송**한다. 메시지 1개당 파일 1개(`/tmp/msg1.txt`, `/tmp/msg2.txt` …).
```
# 1) 작성 — heredoc 안에서는 개행이 그대로 개행으로 들어간다
cat > /tmp/msg1.txt <<'EOF'
📰 ...
━━━ 건설/부동산 ━━━
기사 제목
https://tinyurl.com/xxxxxxx

기사 제목
https://tinyurl.com/xxxxxxx
EOF

# 2) 발송 직전 전문 출력 (필수 — Actions 로그에 실제 발송본을 남겨 형식 검증)
cat /tmp/msg1.txt

# 3) 발송 — text@파일 형식이면 curl이 파일 내용의 개행을 %0A로 정확히 인코딩
curl -s "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d "chat_id=${TELEGRAM_CHAT_ID}" --data-urlencode "text@/tmp/msg1.txt"
```

**줄바꿈 절대 규칙 (2026-07-27 사용자 지적)**: 셸 인자 안에 `\n`(백슬래시+n) 두 글자를 넣으면 curl이 그 두 글자를 그대로 인코딩해 **Telegram에 리터럴 `\n`이 텍스트로 표시된다**. 개행은 언제나 파일 안의 진짜 줄바꿈이어야 하고, 발송은 위의 `text@파일` 형식으로만 한다. `--data-urlencode "text=...\n..."` 직접 전달 금지.

plain text, 3000자 초과 시 분할, 한국어.

**시간 윈도우**: `pool.json`의 `windows_kst` 필드가 확정값 (방식1: 평일 전날22:00~06:10 / 월 금14:00~월06:10, 방식3: 항상 24h). collect.py가 계산·적용 완료. 프롬프트에서 재계산하지 않는다.

**절대 금지**
1. pool.json 밖 기사 임의 추가 금지 (폴백은 `--adhoc-*`로만).
2. 윈도우 자의적 확대·창밖 기사 포함 금지.
3. 날짜/URL 확인 불가 기사 포함 금지 (`url` 필드 없는 기사 발송 금지).
4. 거짓말/수치 조작 금지. 모르면 "미확보". 폴백 카운트 거짓 기록 금지.
5. 검증되지 않은 내용 추가 금지. 방식3 요약은 기사 제목·RSS 메타 범위 내에서만 작성 (본문 미확인 시 제목 기반 1문장으로 제한).
6. 대시보드·통계 페이지·위키피디아는 방식3에서 제외.
7. 정치 뉴스 필터 (공통 지침 1) 적용.

6. **TinyURL 축약**: 선별 확정된 기사만 (최대 46건).
6. **게이트 검증** (§0 전체) → **발송** (§8 메시지 구성) → 완료 보고.

═══════════════════════════════════════
